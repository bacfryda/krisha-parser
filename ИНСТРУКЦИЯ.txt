  KRISHA PARSER BOT — ИНСТРУКЦИЯ ПО УСТАНОВКЕ
═══════════════════════════════════════════════════════

ТРЕБОВАНИЯ:
  1. Windows 10/11
  2. Google Chrome (последняя версия)
  3. Node.js 18+ (скачать: https://nodejs.org)

═══════════════════════════════════════════════════════

УСТАНОВКА:

  1. Распакуйте этот архив в любую папку
  2. Запустите KrishaParser.exe
  3. При ПЕРВОМ запуске подождите 1-2 минуты —
     программа распакует WhatsApp сервер
     (будет показано окно прогресса)
  4. После загрузки откроется главное окно

═══════════════════════════════════════════════════════

ПЕРВАЯ НАСТРОЙКА:

  1. KRISHA.KZ:
     - В браузере Krisha (левая часть окна) войдите
       в свой аккаунт через «Личный кабинет»
     - Или введите телефон/пароль в диалоге авторизации

  2. WHATSAPP:
     - Переключитесь на вкладку «WhatsApp»
     - Дождитесь появления QR-кода
     - Откройте WhatsApp на телефоне:
       Настройки → Связанные устройства → Привязка
     - Отсканируйте QR-код

  3. НАСТРОЙКИ:
     - Вкладка «Фильтры» — выберите регион, комнаты,
       цену и другие параметры поиска
     - Вкладка «Настройки» — API ключ DeepSeek,
       лимит рассылки, шаблон сообщения

═══════════════════════════════════════════════════════

ИСПОЛЬЗОВАНИЕ:

  • «Парсить» — собирает объявления и номера телефонов
  • «Рассылка» — отправляет сообщения через WhatsApp
  • «AI Бот» — автоматически отвечает на входящие

═══════════════════════════════════════════════════════

ВАЖНО:
  • НЕ удаляйте файлы из папки программы
  • Файлы config.json и phones.db создаются при
    первом запуске — в них ваши настройки и база
  • При проблемах — перезапустите программу
