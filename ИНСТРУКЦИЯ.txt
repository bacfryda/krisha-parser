KRISHA PARSER BOT v3.0 — ИНСТРУКЦИЯ ПО ИСПОЛЬЗОВАНИЮ
=====================================================

ЧТО ДЕЛАЕТ ПРОГРАММА

Krisha Parser Bot — это программа для автоматического сбора номеров
телефонов с объявлений на krisha.kz и рассылки сообщений через WhatsApp.

Программа работает в трёх режимах:

1. Парсинг — собирает объявления с krisha.kz и извлекает номера
   телефонов продавцов
2. Рассылка — отправляет сообщения собранным контактам через WhatsApp
3. AI Риелтор — автоматически отвечает на входящие сообщения в WhatsApp
   с помощью искусственного интеллекта


=====================================================
ПЕРВЫЙ ЗАПУСК
=====================================================

Запустите файл KrishaParser.exe. При первом запуске программа подготовит
необходимые файлы — это может занять около минуты.

После запуска вы увидите окно программы: слева встроенный браузер Chrome
с сайтом krisha.kz, справа панель управления с логами.


Шаг 1. Авторизация на Krisha.kz
--------------------------------

Браузер автоматически откроет krisha.kz. Войдите в свой аккаунт — это
необходимо для доступа к номерам телефонов в объявлениях. Без авторизации
парсер не сможет извлекать телефоны.


Шаг 2. Подключение WhatsApp
----------------------------

Переключитесь на вкладку "WhatsApp" в верхней панели. Дождитесь появления
QR-кода. Откройте WhatsApp на телефоне:

   WhatsApp → Настройки → Связанные устройства → Привязать устройство

Отсканируйте QR-код с экрана. После успешного сканирования статус
изменится на "WA: подключён".


=====================================================
РЕЖИМ ПАРСИНГ
=====================================================

Это основной режим работы. Парсер собирает объявления с krisha.kz
и извлекает номера телефонов.


Настройка фильтров
-------------------

Перед запуском парсинга настройте фильтры в правой панели:

Регион — выберите город или область. Например, Астана, Алматы, Шымкент.

Комнаты — отметьте нужное количество комнат: 1, 2, 3, 4 или 5+.
Можно выбрать несколько.

Цена — укажите диапазон цены в тенге. Поля "От" и "До".

Объявлений — сколько объявлений нужно собрать. Можно указать от 1 до 500.
По умолчанию 60. Парсер будет листать страницы, пока не наберёт указанное
количество.

Есть фото — если включено, парсер будет собирать только объявления
с фотографиями.

Новостройки — фильтр по новостройкам на сайте krisha.kz.

От хозяев — только объявления от собственников.

Пропускать застройщиков — если включено, объявления от застройщиков
и строительных компаний будут автоматически исключены из результатов.
Парсер определяет застройщиков по бейджу "Новостройка" на карточке
объявления. Если на странице все объявления от застройщиков, парсер
автоматически перейдёт на следующую страницу.

Также доступны дополнительные фильтры: тип дома (кирпичный, панельный,
монолитный), этаж, год постройки, площадь, площадь кухни и другие.

После настройки нажмите кнопку "Сохранить фильтры".


Запуск парсинга
---------------

Нажмите кнопку "Парсить" в верхней панели. Парсер выполнит следующее:

1. Откроет страницу поиска на krisha.kz
2. Применит все настроенные фильтры кликами, как обычный пользователь
3. Нажмёт кнопку "Показать результаты"
4. Начнёт собирать карточки объявлений со страниц результатов
5. Если включён фильтр застройщиков — исключит их из списка
6. Для каждого объявления откроет его страницу, нажмёт кнопку
   "Показать телефон", решит CAPTCHA если потребуется, и сохранит
   номер в базу данных

Прогресс отображается в прогресс-баре вверху и в логе справа.
Вы увидите сообщения вида:
   (1/60) 2-комнатная квартира · 55 м²...
   Номер найден: +77780171186

Для остановки нажмите кнопку "Стоп". Парсер завершит обработку
текущего объявления и остановится.


=====================================================
РЕЖИМ WHATSAPP
=====================================================

Переключитесь на вкладку "WhatsApp" в верхней панели.


Рассылка
--------

Нажмите кнопку "Рассылка". Бот начнёт отправлять сообщения собранным
контактам через WhatsApp. Между сообщениями соблюдается задержка
(по умолчанию 30 секунд) и дневной лимит (по умолчанию 50 сообщений
в день).

Текст первого сообщения можно настроить в разделе настроек WhatsApp.


AI Бот
------

Нажмите кнопку "AI Бот". Бот начнёт автоматически отвечать на входящие
сообщения в WhatsApp. Он использует искусственный интеллект (DeepSeek)
и ведёт себя как опытный риелтор — предлагает услуги, отвечает на
вопросы клиентов, договаривается о встрече.

Бот работает в фоне и отвечает на все новые входящие сообщения,
пока включён.


=====================================================
КНОПКА "ВЫХОД"
=====================================================

В правом верхнем углу есть кнопка "Выход" с выпадающим меню:

— Выйти из Крыши — разлогинивает аккаунт krisha.kz
— Выйти из WhatsApp — удаляет сессию WhatsApp, потребуется повторное
  сканирование QR-кода


=====================================================
ВАЖНАЯ ИНФОРМАЦИЯ
=====================================================

Не удаляйте файлы из папки программы — все компоненты взаимосвязаны.

Файл config.json содержит все ваши настройки. При переустановке
программы можно сохранить этот файл, чтобы не настраивать фильтры
заново.

Файл phones.db — база данных собранных номеров. При переустановке
сохраните его, чтобы не потерять собранные контакты.

Папка sessions — содержит сессию авторизации krisha.kz. При сохранении
этой папки не потребуется повторная авторизация.
