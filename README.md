# Krisha Parser Bot

Автоматический парсер объявлений с krisha.kz с интеграцией WhatsApp и AI-ботом.

## Установка

1. Установите Python 3.11 или выше
2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Установите Node.js 18+ для WhatsApp сервера
4. Установите зависимости WA-сервера:
```bash
cd wa-server
npm install
cd ..
```

## Запуск

```bash
python main.py
```

## Первый запуск

1. **Авторизация на Krisha.kz:**
   - Откройте вкладку "Крыша"
   - Нажмите "Войти на Krisha.kz"
   - Введите телефон и пароль
   - Дождитесь авторизации

2. **Подключение WhatsApp:**
   - Откройте вкладку "WhatsApp"
   - Нажмите "Запустить WA-сервер"
   - Отсканируйте QR-код в приложении WhatsApp
   - Дождитесь подключения

3. **Настройка фильтров:**
   - Откройте вкладку "Фильтры"
   - Выберите регион, количество комнат, цену и другие параметры
   - Нажмите "Сохранить"

4. **Запуск парсинга:**
   - Откройте вкладку "Парсинг"
   - Нажмите "Старт"
   - Парсер соберёт объявления и извлечёт номера телефонов

5. **Рассылка:**
   - Откройте вкладку "Рассылка"
   - Настройте AI-бота (модель, промпт)
   - Нажмите "Старт рассылки"
   - Бот автоматически отправит сообщения через WhatsApp

## Возможности

- Парсинг объявлений с krisha.kz с антидетектом
- Автоматическое извлечение номеров телефонов
- Интеграция с WhatsApp Web
- AI-бот для генерации персонализированных сообщений
- База данных контактов
- Дневной лимит рассылки
- Проверка наличия WhatsApp у контактов

Для создания исполняемого файла:

