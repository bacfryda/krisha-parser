# Krisha Parser Bot v3.0

Автоматический парсер объявлений с krisha.kz с встроенным браузером, WhatsApp рассылкой и AI-ботом.

## Что делает программа

1. **Парсинг** — открывает krisha.kz во встроенном браузере, применяет фильтры, собирает объявления и извлекает номера телефонов продавцов
2. **Рассылка** — отправляет сообщения через WhatsApp собранным контактам
3. **AI Риелтор** — автоматически отвечает на входящие сообщения в WhatsApp с помощью AI (DeepSeek)

## Установка

### Из исходников

1. Python 3.11+ и Node.js 18+
2. Установите зависимости:

```bash
pip install -r requirements.txt
cd wa-server && npm install && cd ..
playwright install chromium
```

3. Запуск:

```bash
python main.py
```

### Из готовой сборки (.exe)

1. Запустите `KrishaParser.exe`
2. При первом запуске программа автоматически подготовит файлы (может занять минуту)

## Первый запуск

При запуске программа покажет окно с встроенным браузером Chrome и панелью управления справа.

### 1. Авторизация на Krisha.kz

Браузер автоматически откроет krisha.kz. Авторизуйтесь через свой аккаунт — это нужно для доступа к номерам телефонов в объявлениях.

### 2. Подключение WhatsApp

Переключитесь на вкладку **WhatsApp** в верхней панели. Появится QR-код — отсканируйте его в приложении WhatsApp на телефоне:

> WhatsApp → Настройки → Связанные устройства → Привязать устройство

После сканирования статус изменится на "WA: подключён".

## Режим Парсинг

### Настройка фильтров

В правой панели настройте фильтры поиска:

- **Регион** — город или область (Астана, Алматы и т.д.)
- **Комнаты** — количество комнат (1, 2, 3, 4, 5+)
- **Цена** — диапазон цены (от — до)
- **Объявлений** — сколько объявлений собрать (1–500, по умолчанию 60)
- **Есть фото** — только объявления с фотографиями
- **Новостройки** — фильтр по новостройкам
- **От хозяев** — только от собственников
- **Пропускать застройщиков** — исключить объявления от застройщиков и компаний (определяются по бейджу "Новостройка" на krisha.kz)
- Дополнительные фильтры: тип дома, этаж, год постройки, площадь и т.д.

После настройки нажмите **Сохранить фильтры**.

### Запуск парсинга

1. Нажмите кнопку **Парсить** в верхней панели
2. Парсер откроет страницу поиска, применит фильтры кликами (как человек), и начнёт собирать карточки
3. Если включён фильтр "Пропускать застройщиков" — объявления от застройщиков автоматически исключаются. Парсер продолжает листать страницы, пока не наберёт указанное количество объявлений от физ. лиц
4. Для каждого объявления парсер открывает страницу, нажимает "Показать телефон", решает CAPTCHA если нужно, и сохраняет номер в базу
5. Прогресс отображается в прогресс-баре и логе справа

### Остановка

Нажмите **Стоп** — парсер завершит текущее объявление и остановится.

## Режим WhatsApp

Переключитесь на вкладку **WhatsApp** в верхней панели.

### Рассылка

1. Нажмите **Рассылка** — бот начнёт отправлять сообщения собранным контактам через WhatsApp
2. Настройки рассылки: задержка между сообщениями, дневной лимит, текст первого сообщения

### AI Бот

1. Нажмите **AI Бот** — бот начнёт автоматически отвечать на входящие сообщения
2. Используется DeepSeek API для генерации ответов
3. Бот ведёт себя как опытный риелтор — предлагает услуги, отвечает на вопросы

## Настройки

Все настройки хранятся в `config.json`:

| Параметр | Описание | По умолчанию |
|----------|----------|-------------|
| `max_listings` | Количество объявлений для парсинга | 60 |
| `skip_developers` | Пропускать застройщиков | false |
| `toolbar_offset` | Смещение тулбара Chrome (для DPI) | 155 |
| `message_delay_seconds` | Задержка между сообщениями WA | 30 |
| `daily_limit` | Дневной лимит рассылки | 50 |

## Сборка .exe

```bash
python build_release.py
```

Скрипт выполнит:
1. PyInstaller → exe
2. Копирование wa-server + встроенный Node.js
3. Копирование Playwright browsers (Chromium)
4. Создание Inno Setup скрипта для инсталлятора

Готовая сборка: `dist/KrishaParser/KrishaParser.exe`

Для создания инсталлятора: откройте `dist/installer.iss` в [Inno Setup](https://jrsoftware.org/isdl.php) и нажмите Compile.

## Срок действия

Программа работает до **30 апреля 2026 года**. После этой даты при запуске отобразится уведомление об истечении срока.

## Техническая информация

- **GUI**: PyQt6 с встроенным Chrome через win32gui API
- **Парсинг**: Playwright (Chromium) с антидетектом
- **WhatsApp**: whatsapp-web.js (Node.js сервер на порту 3457)
- **AI**: DeepSeek API
- **БД**: SQLite (phones.db)
- **CAPTCHA**: reCAPTCHA v2 (бесплатный аудио-метод + AntiCaptcha API)
